Technical Implementation Overview

Senior-engineer-grade computer vision pipeline

1. Scoreboard Detection

Uses normalized cross-correlation (NCC) on the lane number indicator ("6") to track visibility across panning frames. Bypasses pin-deck views and animations automatically.

2. Active Turn Segmentation

Scans the player initials column using RGB color thresholding to detect the active player row. Automatically inverts crops for active players to ensure uniform binarization.

3. Temporal Voting & Scoring

Employs global majority voting across visible frames (minimum 5 votes) to filter transient motion blur. Scores are calculated dynamically using official bowling strike and spare rules.

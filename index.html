Computer Vision Pipeline

Technical design and implementation methodology

1. Scoreboard Detection

Uses normalized cross-correlation (NCC) of a static template matching the lane number ("6") to detect frame-by-frame scoreboard visibility. This reliably bypasses cartoon animations and secondary status screens.

2. Active Row Segmentation

Scans the player initials column using RGB color thresholding to locate the yellow-orange active turn indicator. Crops active player names dynamically from the top status bar.

3. Temporal Filtering & OCR

Crops Roll 1 and Roll 2 ROIs from each frame column. Grayscale templates of rolls (X, /, -, 1-9) are matched using NCC. A temporal filter requires 5 consecutive matching frames to latch/commit rolls.
